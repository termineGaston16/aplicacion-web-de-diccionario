Su desafío es desarrollar esta aplicación web de diccionario utilizando la API de diccionario {https://dictionaryapi.dev/} y lograr que se parezca lo más posible al diseño.

Puedes usar cualquier herramienta que te guste para ayudarte a completar el desafío. Así que, si hay algo que te gustaría practicar, no dudes en intentarlo.

Sus usuarios deberían poder:

Busque palabras utilizando el campo de entrada
Vea la respuesta de la API del Diccionario gratuito para la palabra buscada
Ver un mensaje de validación de formulario al intentar enviar un formulario en blanco
Reproducir el archivo de audio de una palabra cuando esté disponible
Cambiar entre fuentes serif, sans serif y monoespaciadas
Cambiar entre temas claros y oscuros
Ver el diseño óptimo para la interfaz según el tamaño de la pantalla de su dispositivo
Ver estados de desplazamiento y enfoque para todos los elementos interactivos en la página
Bono : Elige el esquema de colores correcto según las preferencias de tu computadora. 
Sugerencia : investiga prefers-color-schemesobre CSS.
